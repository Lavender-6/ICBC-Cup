# 工银科创桥 — 硬科技企业里程碑式投贷联动平台

> 第十七届「工行杯」全国大学生金融科技创新大赛 · 科技金融方向

---

## 一、项目概述

### 1.1 项目定位

面向硬科技企业（半导体/航天/生物医药/高端装备/新材料/人工智能）的**里程碑式投贷联动平台**。通过 AI 评估引擎对轻资产科创企业进行动态估值，以研发里程碑为触发器，动态匹配金融工具包（知识产权质押贷/投贷联动/供应链金融等），将传统「静态审批」变为「动态授信」。

### 1.2 解决的核心痛点

| 痛点 | 现状 | 本平台方案 |
|------|------|-----------|
| 银行不敢贷 | 研发周期长、早期现金流为负、缺乏可抵押物 | 以专利引用网络+团队画像为非财务估值依据，里程碑进度驱动动态授信 |
| VC不敢投 | 早期估值困难、退出周期不确定 | AI估值引擎输出动态估值+风险评分，为投资决策提供量化依据 |
| 保险不敢保 | 研发失败风险无法定价 | 基于真实企业破产数据集训练XGBoost风险预测模型，输出破产概率 |

### 1.3 里程碑-金融工具映射

| 研发里程碑 | 对应金融工具 | 授信比例 |
|---|---|---|
| ① 立项/预研完成 | 知识产权质押贷 + 研发补贴 | 15% |
| ② 原型验证通过 | AI动态估值授信 + 股权跟投 | 25% |
| ③ 流片成功/临床II期 | 投贷联动（银行授信+VC跟投） | 40% |
| ④ 商业化量产 | 供应链票据 + 订单融资 | 30% |
| ⑤ 上市预备 | 可转债 + 科创专项债券 | 50% |

## 三、AI 模型实现

### 3.1 XGBoost 估值预测模型

**目标**：预测硬科技企业的基础估值和当前估值

| 项目 | 说明 |
|------|------|
| 训练数据 | 2000条模拟硬科技企业数据（含非线性关系+交互项+噪声） |
| 特征数 | 8个（行业、阶段、专利数、专利质量、团队评分、研发占比、员工数、成立年份） |
| 模型 | XGBoost Regressor（OneHot编码 + 300棵树 + max_depth=6） |
| 基础估值 R² | 0.927 |
| 当前估值 R² | 0.954 |
| 模型文件 | `ai/export/valuation_model.joblib`（3MB） |

**特征工程**：
- 类别特征：OneHotEncoder（行业6类 + 阶段5类）
- 数值特征：passthrough（专利数、质量、团队评分、研发占比、员工数、年份）
- 训练数据包含非线性项：`patent_count^0.7`、`team_score^1.5`、`log(employee_count)`、交互项 `(quality × team_score)^0.5`

### 3.2 XGBoost 破产风险预测模型

**目标**：基于企业财务指标预测破产概率，作为风险评分

| 项目 | 说明 |
|------|------|
| 训练数据 | 台湾企业破产数据集（6819条 × 95个财务特征） |
| 类别分布 | 未破产6599条 vs 破产220条（破产率3.23%） |
| 不平衡处理 | scale_pos_weight = 30 |
| 模型 | XGBoost Classifier（300棵树 + max_depth=5） |
| AUC | 0.958 |
| Accuracy | 96.9% |
| 模型文件 | `ai/export/bankruptcy_model.joblib`（585KB） |

**Top 5 重要特征**：
1. Continuous interest rate (after tax) — 12.9%
2. Persistent EPS in the Last Four Seasons — 7.7%
3. Net Income to Total Assets — 7.4%
4. Net worth/Assets — 4.1%
5. Borrowing dependency — 4.1%

### 3.3 专利引用网络分析（PageRank）

| 项目 | 说明 |
=|------|------|
| 算法 | NetworkX PageRank（alpha=0.85） |
| 功能 | 计算专利在引用网络中的中心性，作为专利质量评估维度之一 |
| 可视化 | 折线图（引用趋势+质量评分）+ 力导向网络图（节点大小=PageRank） |

### 3.4 模型推理集成

```
用户请求 /api/enterprises/{id}/valuation
  │
  ├─ 计算特征（专利数、PageRank质量、团队评分等）
  │
  ├─ 估值预测 → XGBoost估值模型 → base_valuation + current_valuation
  │    └─ 模型不可用？→ 回退规则公式
  │
  └─ 风险预测 → XGBoost破产模型 → risk_score（破产概率）
       └─ 模型不可用？→ 回退规则公式
```

**优雅降级**：模型文件不存在或推理失败时，自动回退到规则公式，保证服务可用性。

## 四、功能模块

### 4.1 首页门户

| 模块 | 功能 |
|------|------|
| Hero Banner | SVG横幅展示平台名称+里程碑桥梁图形+金融工具映射 |
| 平台核心能力 | 4个能力卡片：AI评估引擎、里程碑触发动态授信、投贷联动工作台、风控看板 |
| 里程碑投贷联动流程 | 横向5步流程图，展示各研发阶段对应金融工具 |
| 硬科技企业库 | 企业列表表格+创建企业入口 |

### 4.2 企业画像

| 模块 | 功能 |
|------|------|
| 基础信息 | 企业名称、行业、研发阶段、成立年份、员工人数、研发占比 |
| AI估值结果 | 基础估值、当前估值、风险评分、专利数量、平均专利质量、团队评分 |
| 估值来源标识 | 标注估值来自ML模型还是规则公式回退 |

### 4.3 专利引用网络

| 模块 | 功能 |
|------|------|
| 折线图 | 专利引用次数趋势 + 质量评分趋势（双Y轴） |
| 力导向网络图 | 节点大小=PageRank值，颜色=质量等级，可拖拽漫游 |
| 切换 | 支持折线图/网络图一键切换 |

### 4.4 研发团队画像

| 模块 | 功能 |
|------|------|
| 统计概览 | 论文总数、专利总数、总引用数、平均H指数 |
| 成员列表 | 姓名、职位、创始人标识、学历、论文/引用/H指数/专利数 |
| 画像评分 | 基于论文(20%)+引用(20%)+H指数(15%)+专利(25%)+经验(20%)+创始人加分的加权评分 |

### 4.5 里程碑看板

| 模块 | 功能 |
|------|------|
| 时间线展示 | 按研发阶段排序，显示预期/实际日期、进度条、状态标签 |
| 进度更新 | 拖动滑块实时更新进度，自动联动状态（0=待启动, >0=进行中, 100%=已完成） |
| 金融工具 | 点击查看当前里程碑触发的金融工具包及授信金额 |

### 4.6 授信模拟器

| 模块 | 功能 |
|------|------|
| 进度滑块 | 拖动里程碑进度（0-100%） |
| 实时计算 | 基础额度 × 进度系数 × 风险系数 = 最终授信额度 |
| 结果展示 | 基础额度、进度系数、风险系数、最终授信额度 |
| 公式说明 | 最终额度 = 基础额度 × 里程碑进度系数 × 风险评估系数 |

**授信公式**：
```
基础额度 = AI估值 × 30%
进度系数 = 里程碑进度（0-1）
风险系数 = 1 - 风险评分 × 0.5
最终授信 = 基础额度 × 进度系数 × 风险系数
```

### 4.7 风控预警

| 模块 | 功能 |
|------|------|
| 风险评分趋势图 | ECharts双线图：风险评分(%) + 里程碑进度(%) |
| 检查风险预警 | 点击按钮实时计算当前预警 |
| 预警类型 | 里程碑延迟（actual_date > expected_date）、进度偏低（progress < 30%） |
| 预警生命周期 | 预警信息仅存在于当前页面内存，关闭网页即清除，不持久化 |

| 模块 | 方法 | 路径 | 功能 |
|------|------|------|------|
| 企业 | GET | `/api/enterprises` | 企业列表 |
| 企业 | POST | `/api/enterprises` | 创建企业（自动生成专利/团队/里程碑/财务特征） |

### 6.2 数据模型

```
Enterprise（企业）
  ├── Patent（专利） ── PatentCitation（引用关系）
```

## 七、项目亮点

### 7.1 真实AI模型驱动

- **不再是规则公式**：估值和风险评分均由训练好的XGBoost模型推理产出
- **双模型协同**：估值模型（R²>0.92）+ 破产风险模型（AUC=0.958）
- **真实数据集**：破产风险模型基于台湾6819条企业财务数据训练
- **优雅降级**：模型不可用时自动回退规则公式，保证服务可用

### 7.2 里程碑驱动的动态授信

- 传统静态审批 → 研发进度实时驱动授信额度变化
- 5个里程碑阶段对应5套金融工具包，精准匹配融资需求
- 进度滑块拖动即实时计算，所见即所得

### 7.3 专利引用网络分析

- NetworkX PageRank图算法计算专利中心性
- 力导向网络图可视化，节点大小反映专利影响力
- 专利质量综合评估：引用(30%) + PageRank(25%) + 同族(20%) + 国际(15%) + 诉讼(10%)

### 7.4 全应用深色科技主题

- 三色体系（深蓝+工行红+金色）呼应工行品牌
- 玻璃拟态卡片风格，ECharts图表深色适配
- 首页SVG横幅无缝融入背景，桥梁图形直观展示投贷联动
