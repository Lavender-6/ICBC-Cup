# 工银科创桥 · 项目结构示意图

## 技术栈

| 层级 | 技术 | 版本 |
|------|------|------|
| 前端框架 | Vue 3 + TypeScript | Vue 3.4 / TS 5.4 |
| UI 组件库 | Element Plus | 2.7+ |
| 图表库 | ECharts + vue-echarts | 5.5 / 7.0 |
| 路由 | Vue Router | 4.3 |
| HTTP | Axios | 1.7 |
| 构建工具 | Vite | 5.2 |
| 后端框架 | FastAPI (Python) | 0.111+ |
| ORM | SQLAlchemy | 2.0+ |
| 数据库 | SQLite | 内置 |
| AI 模型 | XGBoost + scikit-learn | 2.0 / 1.5 |
| 图分析 | NetworkX (PageRank) | 3.2 |
| 部署 | Vercel (前端) + SSH隧道/Docker (后端) | - |

## 数据流

```
用户操作 → Vue组件 → Axios请求 → FastAPI路由 → Service业务层
                                                         │
                                    ┌────────────────────┤
                                    │                    │
                              ┌─────▼─────┐      ┌──────▼──────┐
                              │ AI模型推理  │      │  SQLite DB   │
                              │ (XGBoost)  │      │ (SQLAlchemy) │
                              └─────┬─────┘      └──────┬──────┘
                                    │                    │
                                    └────────┬───────────┘
                                             │
                                      JSON响应 → Axios → Vue组件 → ECharts渲染
```

## 核心功能模块

| 模块 | 前端组件 | 后端路由 | AI/算法 |
|------|----------|----------|---------|
| 企业画像 | EnterpriseProfile | GET /enterprises/{id}/valuation | XGBoost估值模型 |
| 专利分析 | PatentNetworkGraph | GET /enterprises/{id}/patents | NetworkX PageRank |
| 团队画像 | TeamPortrait | GET /enterprises/{id}/team | 加权评分公式 |
| 里程碑看板 | MilestoneBoard | /milestones/* | 阶段→金融工具映射 |
| 授信模拟 | CreditSimulator | POST /credit/simulate | 进度×风险系数 |
| 风控预警 | RiskWarning | POST /credit/alerts/check | 规则引擎+技术路线变更检测 |
| 数据大屏 | Dashboard | GET /stats/dashboard | 聚合统计 |
| 企业对比 | EnterpriseList | GET /enterprises | 雷达图归一化 |
| 数据导出 | EnterpriseDetail | GET /enterprises/{id}/export | CSV生成 |
