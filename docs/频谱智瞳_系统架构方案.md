## 二、技术栈映射表

| 层级 | 技术选型 | 对应华为云产品 | 用途 |
|------|---------|--------------|------|
| **前端** | Vue3 + ECharts + WebSocket | CCF 云函数 | 可视化 Demo 页，瀑布图、星座图、结果卡片 |
| **后端** | FastAPI / Go | CFC 云函数 | REST API 网关，任务调度 |
| **AI 推理** | 自训模型 → ONNX → ModelArts 推理 | ModelArts 推理服务 | 信号分类（调制识别）、参数估计（SNR） |
| **数据处理** | 自研 Python 模块 | CFC 云函数 | IQ 数据预处理、瀑布图/星座图生成 |
| **数据存储** | MySQL + Redis | RDS MySQL / 云 Redis | 用户管理、数据集管理、识别记录、缓存 |
| **文件存储** | OBS | 对象存储服务 | 存储上传的 .npy/.wav 数据集文件 |
| **代码开发** | VS Code / PyCharm | 码道 CodeArts 代码智能体 | 全链路代码生成、续写、调试、单元测试 |

## 三、数据流设计

```
用户 → 上传数据集(.npy/.wav)
    │
    ▼
[后端] 验证格式 → 存 OBS + 建记录(RDS)
    │
    ▼
[触发] 调用 AI 推理服务(ModelArts)
    │
    ├─ 预处理：IQ 降采样 / FFT / 分帧 → 频谱特征图
    │       星座图点云提取
    │
    ├─ 推理：信号分类模型 → 调制方式 + 置信度
    │       参数估计模型 → SNR / 符号率
    │
    └─ 结果：写回 RDS → Redis 缓存 → WebSocket 推送
    │
    ▼
[前端] ECharts 瀑布图（横轴:时间  纵轴:频率  色:功率）
    星座图（I-Q 散点）
    识别结果卡片（调制方式 / 置信度 / SNR）
    异常告警区（如有干扰检测）
```

## 五、AI 模型方案

### 5.1 信号分类（调制识别）

| 模型 | 输入 | 输出 | 训练数据 |
|------|------|------|---------|
| CNN 分类模型 | 频谱瀑布图（64×64 像素） | 调制方式 + 置信度 | RadioML 2018.01a (DeepSig) |
| 调制方式 | AM, FM, BPSK, QPSK, 16QAM, 64QAM, WBFM, AM-SSB, AM-DSB | | |
| 识别准确率 | ~90%（R45/SNR 场景） | | |

### 5.2 参数估计

| 参数 | 方法 | 模型 |
|------|------|------|
| SNR 估计 | 回归模型 | 多任务回归网络（分类+回归联合训练） |
| 载波频率偏移 | 频域峰值搜索 | 快速傅里叶变换 + 峰值检测 |
| 符号率估计 | 循环平稳检测 | 循环谱分析 |

### 5.3 模型部署路径

```
Python 训练 → ONNX 格式 → 上传 ModelArts → 推理端点 → REST API
                                           ↑
                               华为云 ModelArts 服务
```

## 七、关键技术风险与对策

| 风险 | 概率 | 对策 |
|------|------|------|
| 模型精度不够（识别率 <85%） | 中 | RadioML 是工业级公开数据集，CNN 在 R45 场景可达 90%+，风险可控 |
| 实时性不足（瀑布图延迟高） | 低 | 预计算+缓存：数据预处理与推理异步化，WebSocket 推送结果 |
| 华为云资源不够用 | 低 | 赛题1有代金券支持，MaaS Token 和 RDS/Redis 按量计费 |
| CodeArts 生成代码质量差 | 低 | CodeArts 基于 GLM-5 模型，Java/Python 能力已验证，关键模块人工 Review |

## 八、创新点提炼（答辩用）

1. **AI 赋能传统通信教学**：把抽象的调制识别理论可视化，学生可上传任意信号验证课堂知识
2. **端到端闭环**：从数据采集 → 预处理 → AI 推理 → 可视化，全流程云端化
3. **工业场景延伸**：无线电监测、频谱管理、通信基站运维均可复用
4. **华为云全栈实践**：CodeArts → ModelArts → RDS → Redis → OBS，完整体现产品价值
