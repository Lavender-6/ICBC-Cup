# 工银科创桥 — 硬科技企业里程碑式投贷联动平台

**参赛赛事**：第十七届「工行杯」全国大学生金融科技创新大赛
**参赛方向**：科技金融

---

## 一、选题背景与痛点

硬科技（半导体/航天/生物医药/高端装备）企业在研发周期内面临三重金融困境：
- 银行不敢贷：研发周期长，早期现金流为负，缺乏可抵押物
- VC不敢投：早期估值困难，退出周期不确定
- 保险不敢保：研发失败风险无法定价

## 二、解决方案

以研发关键节点为触发器，动态匹配金融工具包：

| 研发里程碑 | 对应金融工具 |
|---|---|
| 立项/预研完成 | 知识产权质押贷 + 研发补贴 |
| 原型验证通过 | AI动态估值授信 + 股权跟投 |
| 流片成功/临床II期 | 投贷联动（银行授信+VC跟投） |
| 商业化量产 | 供应链票据 + 订单融资 |
| 上市预备 | 可转债 + 科创专项债券 |

## 三、技术栈

- 前端：Vue3 + ECharts + Element Plus
- 后端：FastAPI + SQLAlchemy
- AI：NetworkX（专利引用网络）+ 估值模型
- 数据：模拟数据 + 公开数据集

## 四、Demo 功能

1. 企业画像页：专利引用网络图 + 研发团队画像 + AI估值
2. 里程碑看板：可视化研发进度，展示可触发的金融工具包
3. 授信模拟器：拖动里程碑滑块，实时显示授信额度变化
4. 风控预警：里程碑延迟/技术路线变更自动预警
