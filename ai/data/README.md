# AI 数据目录

## 数据来源

| 数据源 | 用途 |
|--------|------|
| 国家知识产权局 | 专利引用网络建模 |
| 天眼查/企查查 | 企业基本面验证 |
| CNKI/Web of Science | 研发团队学术产出 |
| Wind/券商研报 | 行业对标估值 |

## 目录结构

```
ai/
├── patent_graph.py      # 专利引用网络建模 (NetworkX)
├── valuation_model.py   # 企业估值模型
├── data/                # 数据目录
└── requirements.txt     # AI 模块依赖
```

## 模拟数据

后端启动时自动生成 3 家模拟企业（半导体/航天/生物医药），
包含专利、团队成员、里程碑等完整数据，用于 Demo 演示。
